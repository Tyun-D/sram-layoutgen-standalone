# OpenYield Canonical SRAM Semantic Contract

Generated by `scripts/openyield_L0_semantic_gap_closure.py`.

## Supported Scope

- single_bank: `True`
- single_implicit_readwrite_port: `True`
- write_mask_supported: `False`
- multi_bank_supported: `False`
- multi_port_supported: `False`
- column_mux_ratio_supported_values: `[1, 2]`

## Unsupported Features

- `multi_bank`
- `multi_port`
- `write_mask`
- `write_size`
- `words_per_row_gt_2`
- `column_mux_ratio_gt_2`

## Derivation Rules

- `logical_to_physical_rows`: num_rows = ceil(num_words / words_per_row)
- `logical_to_physical_cols`: physical_num_cols = word_size * words_per_row
- `words_per_row_to_mux`: column_mux_ratio = words_per_row; words_per_row=1 -> choose_columnmux=False; words_per_row=2 -> choose_columnmux=True; words_per_row>2 -> unsupported_until_column_mux_generalized
- `openyield_num_rows_binding`: OpenYield num_rows = local num_rows
- `openyield_num_cols_binding`: OpenYield num_cols = local physical_num_cols
- `address_width`: row_addr_size = ceil(log2(num_rows)); addr_size = row_addr_size in current OpenYield source
